Configurer la clé API Anthropic

L'analyse texte est générée par Claude via l'API Anthropic. Pour obtenir une clé :

  1. Va sur console.anthropic.com et crée un compte.
  2. Ouvre Settings, puis API Keys.
  3. Clique sur Create Key, donne-lui un nom (par ex. « wowanalyser ») et copie-la.
  4. Ajoute des crédits dans Settings › Billing si nécessaire : l'API n'est pas gratuite au-delà d'un petit crédit d'essai. Une analyse coûte généralement quelques centimes.
  5. Colle la clé ci-dessous. Elle est enregistrée uniquement dans le fichier .env de ton PC et n'est envoyée qu'à l'API Anthropic.

Modèle utilisé : – (modifiable via ANTHROPIC_MODEL dans le .env).
